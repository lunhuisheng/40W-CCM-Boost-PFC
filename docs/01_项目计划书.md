# 40 W CCM Boost PFC 项目计划书

版本：RevB 手工布线与覆铜专项终审阶段版，2026-10-27。RevB 已由项目本人完成主要功能模块器件摆放与全板手工布线，并建立 PGND/AGND 底层分区覆铜。覆铜静态专项终审为 CONDITIONAL GO：可进入最终丝印整理与新版 Gerber/Excellon 本地 CAM 审查，尚未批准直接下单。 本计划不构成硬件功能验收。

## 1. 项目边界与来源

本作品是基于学习开源 Boost PFC 工程后，另行构建的 **40 W 开关行为级 Simulink 模型和 KiCad 硬件工程**。仓库根目录 `README.md` 属于原开源项目资料，其中的硬件示波图、TI 控制平台和性能描述不能作为本作品的个人实测。自主模型来源见 [DESIGN_NOTES](../../simulation/simulink/BoostPFC_Design/DESIGN_NOTES.md) 及 [建模脚本](../../simulation/simulink/BoostPFC_Design/Build_BoostPFC_Design.m)。当前硬件原理图采用 STM32G431 数字控制；未完成固件、焊接或上电。

## 2. 指标及验收口径

| 项目 | 本自主设计目标 | 目前证据层级 |
|---|---:|---|
| 单相输入 | 20、24、28 Vac RMS；50 Hz | 三点开关行为仿真 |
| 输出 | 40 V、1 A、40 Ω、40 W | 三点开关行为仿真 |
| 开关频率 | 50 kHz | 模型参数及 PWM 记录 |
| 稳态输出误差 | ±2% | 最后 100 ms 平均值 |
| 低频输出纹波 | ≤2 Vpp | 稳态窗口峰峰值 |
| 输入 PF | ≥0.95 | 最后 200 ms 端口功率法 |
| 输入电流 THD | ≤10% | 2～40 次谐波计算；**非 IEC 认证** |
| 掉电保持 | 24 Vac、40 Ω 稳态掉电后 10 ms，Vout ≥34 V | 零点及峰值两相位行为仿真 |

这些是本自主模型的验收口径。[原开源 README](../../README.md) 另写有掉电下限 **35 V**、输出纹波 **10%**、效率 **>90%** 和 TI Tiva/C2000 平台，不能与本自主项目的 34 V、2 Vpp 及 STM32 方案混写。效率尚未形成可信验收结论：理想器件对照出现 100.38% 的能量平衡异常，见 [旧结果](../../simulation/simulink/BoostPFC_Design/results/ideal_component_metrics.json)。

## 3. 系统方案

```text
20–28 Vac → J1 / BR1 整流 → R1 预充、K1 条件旁路 → L1
                                                 ├→ Q1 → R2 → 输入回流
                                                 └→ D1 → C1 → J2 / 外部40 Ω负载
R2 Kelvin → U3 电流采样 → MCU 电流 PI ─┐
输出电压、整流电压采样 → MCU 电压 PI ───┼→ PWM → U2 栅极驱动 → Q1
U3 → U4 比较器 → 原始关断 / 硬件锁存 ─┘
```

功率、控制、保护分别由 [最终行为模型](../../simulation/simulink/BoostPFC_Design/BoostPFC_Design_LoadConnection.slx)、[D1 修订原理图](../../hardware/BoostPFC_40W_KiCad/pcb_revA_2026-10-26_d1fix/BoostPFC_40W_RevA.kicad_sch) 和 [原理图核查记录](../../hardware/BoostPFC_40W_KiCad/pcb_revA_2026-10-26_d1fix/D1_FIX_REPORT.md) 支撑；行为保护阈值不能替代硬件过流能力。

## 5. RevB 单独工作计划

1. [RevB 独立工程](../../hardware/BoostPFC_40W_KiCad/pcb_revB_manual_layout_modular/BoostPFC_40W_RevB_ManualLayout.kicad_pcb) 目前有 **83 个封装、557 条走线、81 个过孔、2 个 zone、73 个网络，未连接 0**。主功率、栅极驱动、四端 Kelvin 采样、OCP/硬件锁存、MCU 与辅助电源已由项目本人手工摆放并布线；工具用于规则配置、静态审查和图面生成。
2. 已建立 B.Cu 的 `/PGND`、`/AGND` 分区，静态检查见 [RevB 覆铜终审](../../hardware/BoostPFC_40W_KiCad/revb_ground_final_review_2026-10-27/REVB_GROUND_POUR_FINAL_REVIEW.md)。NT1 单点连接静态 PASS；Kelvin 完整性为 CONDITIONAL；PGND 和 AGND 各分成两个填充连通域，经既有同网走线/贯通焊盘连接，不能表述为连续完整地平面。
3. 下一阶段整理 34 条丝印/旧过孔 DRC Warning，重点核查 `/RECT_IN` 坐标 (42.8,42.2) mm 的已排除 dangling via、C46 地回路及功率回流铜颈；更新丝印后重新 DRC、原理图一致性、机械与温升评估。
4. 经最终人工审查，从新的 RevB 文件哈希导出 Gerber/Excellon 并执行本地 CAM 与厂家工程审核；旧 RevA 制造包不适用于 RevB。未取得人工下单批准前不上传订单、不支付。

## 6. 风险与下一阶段

高优先级：当前磁盘上的 d1fix PCB SHA-256 已变为 `A75EB5F1AA544F93747553D1DA3DADDAACDAE4A744BBE86A5AFFCC99271DB6E7`，历史 CAM 记录使用 `4211E9DF...B325`；当前 RevB PCB SHA-256 也与建立时记录不同。两者均需在未来 PCB 阶段做版本差异与重新检查，不能据旧报告宣称当前文件已通过 CAM。制造 ZIP 本身仍与历史清单哈希一致。

其他风险：28 Vac 线峰升压余量只有约 1.794 V；20 Vac 接载最低 33.664 V，但**负载瞬态没有正式 34 V 下限**；80 V Q1 关断尖峰、C1 纹波寿命、桥堆温升、K1 直流触点任务、硬件 OCP/上电复位时序、实际采样/PWM 延迟未实测。优先下一步是完成丝印与剩余警告处置、RevB 制造前静态复核；有条件进入新版 Gerber/Excellon 本地 CAM。目标于 2026-10-28 继续推进，检查通过并获人工批准后才可能下单。
